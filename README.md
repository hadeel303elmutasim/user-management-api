# User Management API

A lightweight, enterprise-ready RESTful backend service built on top of Node.js and Express, utilizing MongoDB and Mongoose for data persistence. This service provides a robust set of endpoints to handle complete resource lifecycles with industry-standard HTTP methods.

## Features
- **RESTful Architecture:** Clear separation of concerns following strict HTTP method conventions (`POST`, `GET`, `PATCH`, `DELETE`).
- **Data Persistence:** Seamless schema modeling, validation, and object-relational mapping via Mongoose.
- **Robust Error Handling:** Comprehensive request validation and standardized HTTP status responses (`200`, `404`, `500`).
